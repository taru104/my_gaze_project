# 合成視線データによる大規模開発 計画メモ

ユーザ構想: 3D空間に疑似眼球モデルを置き、「どこを見ているか」が既知の状態で
顔+視線データを自作レンダリングし、そこから視線推定モデルを学習する。
実データ収集の限界(正面ばかり・正解が曖昧)を、合成データの無限の正解ラベルで突破する。

---

## なぜ合成データが強力か

- **完全な正解ラベル**: 視線方向・注視点・頭部姿勢・眼球回転・虹彩3D位置が
  レンダリング時に厳密に既知。実データのキャリブ誤差やアノテーション誤差が無い。
- **姿勢を自由に振れる**: 現状の弱点「顔が横向きだとズレる」を、横向きサンプルを
  無限に生成して直接潰せる。ヨー±80°でも均一に学習可能。
- **ドメイン多様性**: 顔形状・肌色・照明・カメラ位置・眼鏡を変えて汎化させられる。
- 既存研究の裏付け: UnityEyes (Wood 2016), SynthesEyes, NVIDIA の合成瞳孔学習など。

---

## ソフトウェア選択の推奨

### 第一候補: **Blender + Python (bpy)** ★推奨
- 無料・オープンソース。Pythonスクリプト(bpy)でシーンを完全自動生成できる。
- ヘッドレス(`blender --background --python gen.py`)で大量バッチレンダリング可能。
- 眼球は球体+虹彩テクスチャ+角膜屈折で物理的に作れる。視線方向=眼球のZ軸回転で厳密制御。
- FLAME/Basel Face Model 等の3D顔モデルを読み込めば人間らしい顔が作れる。
- **インストール**: [blender.org](https://www.blender.org/download/) から本体。
  Python連携は同梱Pythonで完結(追加不要)。学習側は既存の.venv(numpy等)を使う。

### 補助候補: Unity + 既存アセット
- UnityEyes(Cambridge)がまさにこの目的の既製ツール。眼球周辺だけを高速生成。
- リアルタイム性・GUIは強いが、フルバッチ自動化はBlenderの方が素直。
- 顔全体+頭部姿勢まで扱うなら Blender、眼領域クローズアップだけなら UnityEyes。

### 結論
まず **Blender** を入れてほしい。理由: 顔全体+頭部姿勢+眼球を1つのパイプラインで
自動生成でき、本プロジェクトの MediaPipe(478ランドマーク+虹彩) 入力と噛み合う。

## 開発フェーズ (段階的に大規模化)

### Phase 0: 最小疑似眼球レンダラ (1〜2日)
- Blenderで球体眼球1個 + カメラ。視線方向をパラメータ化してレンダ。
- 出力: 画像 + (視線ベクトル, 注視点2D, カメラ内因数) のラベルJSON。
- 目的: パイプライン疎通確認。100枚生成して MediaPipe が虹彩検出できるか確認。

### Phase 1: 顔つき単一アイデンティティ (3〜5日)
- 3D顔メッシュ(FLAME等)に眼球を埋め込む。頭部姿勢(ヨー/ピッチ/ロール)を振る。
- 注視点を画面グリッド上で振り、頭部姿勢と独立にサンプリング。
- 出力を現行の7D特徴抽出([Lx,Ly,Rx,Ry,Pitch,Yaw,dist])に通し、
  実データ(GazeCapture)と特徴分布が一致するか検証(ドメインギャップ測定)。

### Phase 2: 多様性大規模生成 (1〜2週)
- アイデンティティ・肌・照明・カメラ距離・眼鏡有無をランダム化(ドメインランダム化)。
- 10万〜100万フレーム生成。split分割。
- グローバルモデル(現在のMLP)を合成データで事前学習し、実データで微調整。

### Phase 3: sim-to-real と評価 (継続)
- ドメイン適応: 合成学習→実データ(GazeCapture/ユーザ実ログ)でファインチューン。
- 目標: 横向き±60°でも実データで誤差劣化ゼロを維持。
- 疑似眼球の物理(角膜屈折・カッパ角個人差)を実データにフィットさせて逆生成も検討。

---

## アーキテクチャの繋ぎ方 (既存資産の活用)

- 現在の勝ちパイプラインは「7D特徴 → グローバルMLP → 個人補正」。合成データは
  この **グローバルMLPの学習データを無限に供給する** 役割。特徴抽出(features.py)は
  そのまま流用でき、入力が実写でも合成でも MediaPipe を通れば同じ7Dになる。
- つまり合成データ導入は既存コードを壊さず、cache/*.npz を合成分で増やすだけで済む。

4. 学習高速化が必要なら PyTorch GPU 版 / lightgbm 等の追加。
